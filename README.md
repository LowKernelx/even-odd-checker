# Even/Odd Checker in C++

This is a simple C++ program that checks whether an input number is even or odd.

## How It Works

- The program takes an integer input from the user.
- It uses the modulo operator `%` to check if the number is divisible by 2.
- If the number is divisible by 2, it prints that it is even.
- Otherwise, it prints that it is odd.
